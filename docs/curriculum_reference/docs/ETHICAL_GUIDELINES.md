# Ethical & Legal Guidelines

Sqrock IT Solution — Alpha 2 Internship (Cybersecurity Track)

## Strict Rules of Engagement

1. **Authorized Systems ONLY**:
   - All tasks must be performed on lab virtual machines, local host (`localhost` / `127.0.0.1`), your own domains, or explicitly authorized systems.
   - **No exceptions.**

2. **No Real Targets**:
   - Never run phishing, harvesting, or scanning against real users, companies, third-party infrastructure, or live targets.

3. **Data Privacy**:
   - Any data collected during OSINT exercises must be anonymized or permanently deleted after analysis.

4. **Report Vulnerabilities**:
   - If you discover real vulnerabilities accidentally, report them to your supervisor/mentors immediately.

5. **Documentation**:
   - Maintain a lab journal and reproducible code. All experiments must be logged with timestamps and scope notes.

6. **Legal Compliance**:
   - Activities without written authorization violate the **Information Technology Act, 2000 (India)**, the **Computer Fraud and Abuse Act (CFAA - US)**, and **GDPR**.
   - You are personally responsible for all code executed.
