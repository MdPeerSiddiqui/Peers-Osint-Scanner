# Contributing to PEER'S OSINT Scanner

Thank you for your interest in contributing to **PEER'S OSINT Scanner**!

## How to Contribute

1. **Fork the Repository**:
   Click the Fork button at the top right of [MdPeerSiddiqui/Peers-Osint-Scanner](https://github.com/MdPeerSiddiqui/Peers-Osint-Scanner).

2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/Peers-Osint-Scanner.git
   cd Peers-Osint-Scanner
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-osint-feature
   ```

4. **Commit Your Changes**:
   ```bash
   git commit -m "feat: add Shodan API passive scanning"
   ```

5. **Push and Open a Pull Request**:
   Push to your fork and submit a PR to `MdPeerSiddiqui/Peers-Osint-Scanner:main`.

---

## Ethical Standards
All contributions must comply with our strict ethical policies: only non-invasive, passive intelligence techniques are permitted. Invasive scanning or exploit modules are strictly prohibited.
